# Add benchmark material here

Place representative, permitted test material in the category folders:

- `articles/`
- `screenshots/`
- `images/`
- `pdfs/`
- `videos/`
- `notes/`
- `edge-cases/`

Then register each item in `../manifest.json`.

Keep private credentials, tokens, personal documents, and unlicensed copyrighted material out of this directory.
