SQLite FTS5 for Local Search

FTS5 is the full-text search engine built into SQLite. It gives you tokenized search over text columns with ranking, prefix matching, and phrase queries, all without a server. This guide covers the parts you need for a local, offline library.

Creating the virtual table

FTS5 tables are declared like ordinary tables but must include exactly one UNINDEXED column used as the primary key link to your content table. 

CREATE VIRTUAL TABLE items_fts USING fts5(
    item_id UNINDEXED,
    title,
    description,
    body
);

Keeping the index in sync with triggers

Because FTS5 tables are virtual, changes to your content table are not reflected automatically. Attach triggers so inserts, updates, and deletes stay in sync. 

CREATE TRIGGER items_fts_after_insert AFTER INSERT ON items BEGIN
    INSERT INTO items_fts(item_id, title, description, body)
    VALUES (new.id, new.title, new.description, new.body);
END;

Querying

The match operator handles phrases and negation. Quote user input to treat every token as a phrase fragment, then escape embedded quotes. 

SELECT i.*, bm25(items_fts)
FROM items_fts
JOIN items i ON i.id = items_fts.item_id
WHERE items_fts MATCH '"slow" "news"'
ORDER BY bm25(items_fts);

Failure mode

FTS5 may be unavailable when SQLite is compiled without the extension. Detect this at startup and fall back to LIKE queries so search degrades gracefully instead of failing outright.
