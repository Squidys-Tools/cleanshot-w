# Snipsy UI redesign mockups (phase 1)

CleanShot X–inspired mockups for every Snipsy surface, light and dark, using actual
HugeIcons free-set (MIT) icon data.

Open `index.html` in a browser — it has tabs for Editor, History rail, Capture overlay,
Quick access, and Preferences, and a light/dark toggle that flips every surface at once.

Files:

- `design-spec.md` — the full design spec (tokens, GPUI expression notes, per-surface
  measurements, compatibility notes, verified-vs-assumed list)
- `icon-mapping.md` — HugeIcons licensing verdict, every icon's replacement, the complete
  purge list
- `tokens.css` — the design tokens the mockups use (mirrors the GPUI constants in the spec)
- `hugeicons.js` — icon path data extracted from `@hugeicons/core-free-icons`
- `index.html` — the gallery

Icons in these mockups are HugeIcons free-set (MIT): 24×24 stroke-rounded, used unmodified.
